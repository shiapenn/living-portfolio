## 3. Gate 1b+ Implementation Details

### 3.1 First-Run Setup, Login Flow & Default Token Elimination (UX P0-1, `S1`, `20261020-UX-01`)
- **`[implemented]`** Created HTML endpoints for `/admin/login` (`renderAdminLoginPage()`) and `/admin/setup` (`renderAdminSetupPage()`) in `apps/web/src/renderer.ts`.
- **`[implemented]`** Updated `requireAdminMiddleware()` in `apps/api/src/auth/security.ts`: unauthenticated browser navigation (`Accept: text/html`) redirects (HTTP 302) to `/admin/setup` (if not configured) or `/admin/login` (if configured), while API requests continue receiving HTTP 401 JSON.
- **`[implemented]`** Completely removed hard-coded default token `lp_pat_default_test_admin_token_001` from `createApp()` and `apps/api/src/app.ts`. Unconfigured environments boot with no bearer tokens; probe V5 verifies that `lp_pat_default_test_admin_token_001` returns HTTP 401.

### 3.2 Admin Client CSRF, Auth & Honest Error Handling (UX P0-2, `20261020-UX-02`)
- **`[implemented]`** Created `apiClient` helper inside admin workspace scripts attaching `X-CSRF-Token` from `sessionStorage` and `Content-Type: application/json`.
- **`[implemented]`** Enforced `res.ok` verification before reporting success; on HTTP 401 or network error, the UI displays `"Couldn't check for private details"` and never falls through to the green "No confidential secrets" chip.

### 3.3 Server-Side Publish Gate & Confidentiality Scanner (UX P0-3, `S2`, `20261020-UX-03`)
- **`[implemented]`** Broadened `scanForConfidentialData` in `packages/ai/src/extraction/index.ts` to detect `sk-` keys (`sk-proj`, `sk-ant`, `sk-test`, `sk-live`), NDA markers (`\b(?:nda|non-disclosure|confidential)\b`), and client names (`Acme Corp`, `Client ...`).
- **`[implemented]`** Server-side publish gate in `POST /api/entries`: creating an entry with `visibility: 'public'` strictly requires a signed `redactionPreviewToken` matching `bodyHash` and scan results; requests without a token fail with HTTP 400.
- **`[implemented]`** Whitespace and empty body rejection: `EntryCreateSchema` and `RevisionCreateSchema` use `z.string().trim().min(1)` to reject empty or whitespace-only bodies with HTTP 400.

### 3.4 Elimination of Hardcoded UI Claims & Truthful Health Status (UX P0-9, `20261020-UX-05`)
- **`[implemented]`** Deleted hard-coded fictional "Detected Claim Conflict" card from `renderAdminWorkspacePage()`.
- **`[implemented]`** Deleted false `"Background enrichment queued"` claim from post-publish banner.
- **`[implemented]`** Added `aria-pressed` attribute to the kill-switch button initialized asynchronously from server settings (`/api/settings`).
- **`[implemented]`** Updated `/healthz` (`apps/api/src/routes/health.ts`) to return `not_configured` for unconfigured backup and queue subsystems (depth: null, lastRestoreTestStatus: `'not_configured'`).

### 3.5 Ask Safety Engine (Fix 4, `G1`–`G7`)
- **`[implemented]`** `checkGate` in `packages/core/src/algorithms/gateAndRoute.ts` returns `INDETERMINATE` when entry-side hard facets are unknown or missing (`G1`).
- **`[implemented]`** Computed `/api/ask` routing inputs (`hasEvidence`, `hasVerifiedEvidence`, `outcomeStatus`, `hasScope`) dynamically from repository claims and evidence records rather than hardcoding true/worked (`G2`).
- **`[implemented]`** Evaluated confirmed scoped constraints in `checkGate` against visitor facet values and loaded them via `repo.getScopedConstraints('confirmed')` in `ask.ts` (`G3`).
- **`[implemented]`** Loaded domain configuration (`domainConfig`) in `ask.ts` specifying hard and soft facets (`G4`).
- **`[implemented]`** In time-travel mode, `verifyAnswerBeforeDelivery` detects future-year mentions, strips future sentences from `verifiedText`, and `ask.ts` downgrades failed verification responses to extractive excerpts (`G5`).
- **`[implemented]`** Advisory queries with `INDETERMINATE` gate return `tier: 'needs_context'` with `missingFacets` once before escalating (`G6`).
- **`[implemented]`** Synthesized Tier 2 escalation drafts via model provider + `verifyAnswerBeforeDelivery` instead of static placeholder strings (`G7`).

### 3.6 Hard-Code Scanner Extension & Regression Test (Instruction 5)
- **`[implemented]`** Extended `scripts/hardcode-check` with rule `CREDENTIAL_LITERAL_NON_TEST` flagging credential-like tokens (`lp_pat_`, `sk-`, `ghp_`, `AKIA`) in non-test files (`apps/`, `packages/`, `docker/`).
