## 1. Commit Baseline & Explanation of Red CI on `9405d51` (Instruction 2)

### 1.1 Root-Cause Analysis of CI Failures on Commit `9405d51`
CI workflow runs triggered on commit `9405d51` failed due to three infrastructure incompatibilities following the history rewrite:
1. **DCO Check Failure (`scripts/dco-check`):** The GitHub Actions push event passed `github.event.before = 3d10a77`. Because commit `3d10a77` was rewritten and completely removed from repository history, `git rev-list --no-merges 3d10a77..9405d51` failed with `fatal: bad object 3d10a77`.
2. **Gitleaks Action Failure:** The legacy `gitleaks-action` derived its git scan range using `${scanInfo.baseRef}^..${scanInfo.headRef}`. Because the base reference was the root commit (which has no parent), `root^` failed in git.
3. **CodeQL Static Analysis Failure:** The legacy workflow failed on the mandatory Code Scanning upload step (`upload-sarif`), which is not permitted without GitHub Advanced Security on private repositories.
4. **Untested State:** Because the preceding workflow steps halted execution on `9405d51`, the audit governance check (`pnpm audit:check`) and test suites never executed in CI on that commit.

### 1.2 Pushed Baseline
The remediations in this report were pushed as clean, non-force commit `479b6eb` to `origin/main` above `9405d51`.

## 3. Hardened Security & Verification Tooling (Instructions 4 & 5)

### 3.1 DCO Check Hardening ([`scripts/dco-check`](../../scripts/dco-check))
- **`[implemented]`** Hardened `resolveCommitList()` in `scripts/dco-check`: if `DCO_BASE_SHA` is all zeros (`0000000000000000000000000000000000000000`) or is unreachable via `git cat-file -e` (e.g. following history rewrites or force pushes), the script prints an explicit notice:
  `[OSR-07 DCO] Notice: Base commit (...) is unreachable or all zeros (force push / rewritten history / new branch). Falling back to checking full repository history.`
  and inspects every commit in full repository history up to HEAD, rather than crashing or skipping sign-off verification.
- **`[implemented]`** Added conformance regression tests in [`apps/api/src/conformance/dco-check.conformance.test.ts`](../../apps/api/src/conformance/dco-check.conformance.test.ts) asserting that all-zero bases and unreachable bases trigger full history fallback and print the notice.

### 3.2 Gitleaks Hardening ([`scripts/gitleaks-scan`](../../scripts/gitleaks-scan) & [`.github/workflows/secrets.yml`](../../.github/workflows/secrets.yml))
- **`[implemented]`** Pinned explicit binary version `GITLEAKS_VERSION: "8.30.1"`.
- **`[implemented]`** Created [`scripts/gitleaks-scan`](../../scripts/gitleaks-scan) which executes on every push, schedule, and local verification:
  - Scans FULL repository history across all commits on push, schedule, and local runs (`gitleaks git --verbose .`).
  - Scans commit range on pull requests (`--log-opts="--no-merges base..head"`).
  - Explicitly logs the Gitleaks binary version and the number of commits scanned.
