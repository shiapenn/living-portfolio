# Front-End Complete Acceptance Pack (Gate `GFE`)

> [!NOTE]
> Created at Gate G15 closure (2026-11-15) per owner decision: interim gates (`G15`–`G19`) close on CI, journey tests, sweep results, and contact-sheet review; the owner performs one formal hands-on acceptance walkthrough at Milestone **`GFE` ("Front-End Complete")**, positioned after `WP-19` (`G19`) and before `WP-20` (`G20` accessibility sweep, shape polish, and `v0.2.0` release).

## 1. Gate `GFE` Position

- **Predecessor:** `WP-19` / Gate `G19` (Public frame, Work, Writing, Build, Ask, Time Travel).
- **Gate `GFE`:** Owner hands-on acceptance across `J1`–`J11` on a fresh clone on port `4000` (`PORT=4000 ENABLE_BUNDLED_WEB=true pnpm --filter @living-portfolio/api dev`), with all milestone criteria below verified.
- **Successor:** `WP-20` / Gate `G20` (Shape presets, locale readiness, full axe/keyboard sweep, and `v0.2.0` release).

## 2. Milestone Criteria (Gate `GFE`)

1. Fresh clone following `docs/START-HERE.md` Path B starts on port `4000` with zero skipped instructions.
2. Every journey `J1`–`J11` passes by hand without developer tools or workarounds.
3. Zero `P0` or `P1` open findings in `docs/audits/register.yml`.
4. Zero `axe-core` critical or serious violations across all public and admin routes in light and dark mode at `1280 px` and `320 px`.
5. `320 px` and `1280 px` pass with zero horizontal overflow, zero clipped text, and `>= 44 px` touch targets.
6. Every interactive flow works keyboard-only (tab order, visible focus, Esc, arrow keys in menus/tabs/drawers, focus return).
7. No raw technical/test jargon, no `501` controls rendered, and exactly one feedback place active at a time.
